About Sarah

I like taking a problem from raw data to something a person can actually use: a model, a database, a dashboard.

I’m a student at Mar Athanasius College of Engineering, Kothamangalam. Python is where I do most of my work, with interests spanning graph neural networks, explainable machine learning, and data-driven web applications.

My work has included illicit Bitcoin wallet detection at IIIT Kottayam and EEG classification for Alzheimer’s disease and depression. Beyond code, I’ve led the ISTE MACE student chapter and helped bring technical events to life.

02 / Selected work

From questions to projects.

A few ways I’ve put data, models, and software to work.

01

Explainable EEG Classification

  • Python
  • scikit-learn
  • MNE
  • Streamlit

A machine-learning pipeline for EEG recordings, extracting signal features to support classification of Alzheimer’s disease and Major Depressive Disorder.

Inside the project

A dual stacking-ensemble classifier processes the extracted features, with results presented through a Streamlit dashboard.

02

Credit Card Fraud Detection

  • Python
  • Flask
  • scikit-learn
  • Apriori

A web application that scores transaction risk and uses frequent-pattern mining to explain potentially suspicious activity.

Inside the project

A Decision Tree assigns high, medium, or low risk; Apriori identifies patterns in transaction attributes. CSV uploads produce transaction scores, charts, and an overall assessment. Built using a synthetic dataset of 500 transactions, with about 4% labelled as fraud.

03

Eventify

  • Python
  • Flask
  • MySQL
  • SQL

A database-driven platform connecting event organizers with service providers, from event creation to booking and sponsorship matching.

Inside the project

Separate dashboards for organizers and providers, password hashing, session management, and a normalized relational database. Referential integrity and constraints protect active bookings from accidental deletion.
