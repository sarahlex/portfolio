Credit Card Fraud Detection

  • Python
  • Flask
  • Scikit-learn
  • Apriori
  • Pandas

A web application that flags risky transactions. A Decision Tree scores each one and buckets it into high, medium, or low risk. The Apriori algorithm then mines frequent patterns, such as a high amount combined with an international, night-time purchase, to explain why transactions look suspicious.

Users upload a CSV, and the Flask backend returns per-transaction risk scores, an overall assessment, a doughnut chart, and recommendations. It was trained on a synthetic dataset of 500 transactions, about 4% of them fraud.

View on GitHub

Eventify

  • Python
  • Flask
  • MySQL
  • SQL

A database-driven event management platform that connects event organizers with service providers. It rests on a normalized relational database with referential integrity, cascading updates, and constraints that block deletions while active bookings exist.

Organizers and providers get separate dashboards, secured with password hashing and session management. The platform covers event creation, categorized service discovery, booking, and sponsorship matching.
